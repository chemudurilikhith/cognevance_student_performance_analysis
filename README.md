# Student Performance Analysis

## Cognevance Internship – Level 1 Data Analytics Project

### Project Overview

This project was completed as part of my Cognevance internship. The main aim of the project was to analyze student performance using information such as attendance, study hours and subject marks.

I used Python in Google Colab to load the dataset, check and prepare the data, perform the analysis and create visualizations.

### Dataset

The dataset contains information about 300 students.

The main columns include:

- Student ID
- Gender
- Age
- Department
- Attendance Percentage
- Study Hours Per Day
- Sleep Hours Per Day
- Mathematics Marks
- Science Marks
- English Marks
- Average Marks
- Performance

The dataset used in this project is a sample dataset created for learning and analysis purposes.

### Analysis Performed

The project includes analysis of:

- Dataset structure and basic statistics
- Missing values and duplicate records
- Student attendance
- Subject-wise marks
- Overall student performance
- Performance categories
- Attendance and academic performance
- Study hours and academic performance
- Department-wise performance
- Department-wise attendance

### Visualizations

Different charts were created during the analysis, including:

- Attendance distribution
- Subject-wise average marks
- Performance category distribution
- Performance distribution pie chart
- Attendance vs average marks
- Study hours vs average marks
- Department-wise performance
- Department-wise attendance

### Key Observations

- The average attendance in the dataset was approximately 79.82%.
- The overall average mark was approximately 85.82.
- English had the highest average among the three subjects in this sample.
- Attendance showed a positive relationship with average marks.
- Study hours also showed a positive relationship with average marks.
- Department-wise analysis showed differences in average performance and attendance.
